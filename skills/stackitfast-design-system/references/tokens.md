# Tokens

Single source: `packages/ui/src/tokens.ts`. Everything else is derived:

- `packages/ui/src/styles/globals.css` `:root` variables are generated by
  `bun run --cwd packages/ui gen:css`; `cssVars.test.ts` fails if they drift.
- `packages/ui/tailwind.config.ts` maps tokens to classes and builds the prose
  colours (`prose` on paper, `prose-ink` on ink).
- `scripts/contrast-check.mjs --tokens` reads the same file.

Never copy a hex into a component. If a value is missing, add a token.

Legacy tokens (`bg`, `surface.*`, `border.*`, `modes.*`) stay until every
page is migrated; new code prefers the rows above.

**Text colour rule:** apricot is text only on ink (`text-accent`, 8.4:1). On
paper, accent text is `text-accent-ink`. Bare `text-accent` on paper is a bug.

## Share card themes (`cardThemes`)

apricot · ink · peach · cream · rust — each `{ bg, fg, sub, chip }`. Used by
`ShareCard` in the DOM and by the server-side PNG renderer.

## Shape

| Token   | Class             | Value                                         |
| ------- | ----------------- | --------------------------------------------- |
| panel   | `rounded-panel`   | 22px — cards, panels, bands                   |
| control | `rounded-control` | 12px — buttons, inputs, options, code windows |
| chip    | `rounded-chip`    | 6px — chips, small buttons                    |
| tile    | `rounded-tile`    | 22% — icon tiles (the logo tile)              |
| full    | `rounded-full`    | avatars, spinners, progress only              |

`xs/sm/md/lg` (4/6/10/14px) are legacy.

## Motion, layers, widths

- `duration-fast` 150ms · `duration-snap` 220ms · `duration-settle` 520ms ·
  `ease-snap` cubic-bezier(0.2, 0.8, 0.2, 1). See motion.md.
- `z-header` 30 · `z-overlay` 40 · `z-modal` 50 · `z-toast` 60.
- `max-w-content` 1120px (pages) · `max-w-wide` 1200px (header, footer) ·
  `max-w-prose` 720px · `max-w-modal-sm/md/lg`.
