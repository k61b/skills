# Principles — where every rule comes from

STACK IT FAST shows real production stacks and ships the files an AI coding
agent needs to build them. The mark says that in one shape: a block of
**three layers** (a stack) that read as an **S**, whose top layer is a **file
with a folded corner**, on an **apricot tile**. The interface is that shape at
page scale, plus a character so the product feels made by people.

## 1. The shell is the block

The mark's block is warm ink, so the product's shell is warm ink
(`ink #1f1a16`). Cards are one step lighter (`ink-raised`), illustration wells
two steps (`ink-well`). The ink is never pure black and cream is never pure
white — both are tinted, like the mark.

Reading long text on ink is tiring, so anything you read for more than a
minute sits on **paper**: a cream panel inside the ink frame. That keeps the
character at the edges and comfort in the middle.

## 2. Apricot is the tile

The tile is the only colour in the mark, so apricot is the only loud colour
in the UI. It fills **one** primary action per view, marks the emphasis word
in a headline, and colours markers and badges. It always carries ink text
(8.4:1); white on apricot fails and looks cheap.

## 3. Layers and seams

The S is three layers separated by seams. Compositions follow it: three ways
in, three stats, three-layer stack diagrams (Frontend / Backend / Data), a
stack of files fanned out. When layers sit on top of each other, the gap
between them is a seam — surface showing through — not a hairline border.

## 4. The fold means "file"

The folded corner is the most recognisable detail, so it is rationed. It only
appears on things that are files: rule cards, AGENTS.md / SKILL.md / .mdc tabs,
downloadable reports, the code window's active tab. A fold on a random card
dilutes it.

## 5. Rounded like the tile

The tile is rounded (22%), the block inside is sharp. In the UI, containers
take the tile's softness (panels 22px, controls 12px, chips 6px) and content
stays crisp (text, code, file cards with their fold). Pills are gone.

## 6. Type in the wordmark's voice

The wordmark is lowercase Manrope 700 with tight tracking. Headlines follow:
Manrope 800, −0.04em, sentence case, one emphasis word in apricot. Labels are
sentence case with a square marker. Mono is for what is literally code or
data: file names, versions, counts, commands.

## 7. A character, not a mascot sticker sheet

Stacky is the mark with a face: the same three layers, the top one an apricot
file that has just snapped into place. He shows up where a person would —
greeting in the hero, thinking during the survey, celebrating a result,
asleep on a 404, waiting in an empty state — never as wallpaper. Stickers
around him share one hand: thick ink outline, flat fills, hard shadow, cream
die-cut, a round apricot badge.

## 8. Honest and concrete

The product's promise is "real projects, not guesswork", so the UI states
limits and numbers: spec lines under tools ("16 questions · about 2 minutes"),
counts read from the database, sources linked. No vague superlatives.

## What this rules out

Mono uppercase eyebrows · pulsing dots · blur glow blobs · rainbow or
decorative gradients · pills · emoji · white text on apricot · a fold on
something that is not a file · Stacky as decoration with no role.
